An XGBoost (Gradient Boosted Decision Trees) classification model trained offline on tabular geospatial features to predict cell-level deforestation risk scores. 🛡️ Scientific Boundaries & Calibration

  • Probabilistic Calibration: Brier Score = 0.00693; probabilistic calibration is not established. Outputs are interpreted as relative spatial risk scores.
  • UI Confidence / Score Language: UI heuristic / relative spatial risk score — not a calibrated probability.
  • Rare-Event Imbalance: Base deforestation prevalence in 2024 was 0.1419% (10 events in 7,045 units). Default 0.5 classification threshold is uninformative; capacity-based ranking (Top-K) is mathematically required.
  • Retrospective Ranking: Observed lift reflects retrospective ranking evidence, not a measured field-operations efficiency gain.
  • Non-Causal Association: Attributions reflect predictive feature association, not causal explanations of deforestation drivers.

⏳ Temporal Qualification & Data Auditing

  • 2022 Population: Out-of-time static proxy (IBGE 2022 Census published June 28, 2023; municipal hierarchy proxy).
  • 2023 Population: Out-of-time static proxy (published 11 months post monitoring cutoff).
  • 2024 Population: Temporally valid for held-out test (published 1 month before August 1, 2023 monitoring cutoff).
  • Zero Blanket Claim: Blanket zero temporal leakage is not claimed across all periods; each data vintage is partitioned with explicit chronological cutoffs.
  • Deforestation History: Preceding PRODES loss features strictly query data prior to observation year T (Features ≤ T-1 → Labels in Year T).
