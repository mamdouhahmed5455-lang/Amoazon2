Four Environmental Benefit Domains

Ecosystem services supported when primary tropical forest loss is mitigated.

1. Carbon Retention

"Protecting intact forests helps retain carbon stored in vegetation and soils."

Primary tropical rainforest holds large biomass carbon reservoirs. Clearing converts long-term sinks into direct atmospheric emissions and committed future carbon release.

2. Biodiversity Protection

"Maintaining connected forest habitat supports biodiversity and reduces fragmentation pressure."

Preserving continuous canopy buffers vulnerable endemic species against destructive edge effects, microclimate degradation, and territorial isolation.

3. Hydrological Stability

"Amazon forest evapotranspiration contributes to atmospheric moisture recycling and regional hydrological processes."

Intact forest pumping mechanisms support continental atmospheric vapor transport ("flying rivers") vital for regional rainfall distribution across South America.

4. Ecosystem Resilience

"Reducing cumulative disturbance and fragmentation can strengthen ecosystem resilience to drought, fire, and climate stress."

Continuous canopy cover maintains humid forest interior conditions, substantially reducing understory flammability and buffering against compound climate disturbances.

Established Forest Monitoring Systems

Comparing primary purpose, analytical role, and complementary positioning across verified platforms.

INPE PRODES

National Institute for Space Research (INPE)
Official Benchmark
Primary Role & Methodology Official annual consolidated primary forest clear-cut census (≥6.25 ha) using cloud-free optical mosaics (Landsat, Sentinel, CBERS). Retrospective accounting standard since 1988.
Analytical Nature Pure retrospective measurement; deterministic post-event clear-cut mapping without forward-looking risk prediction or sensitivity simulation.
Complementary Relation to This Project PRODES serves as the foundational ground-truth baseline for this project's historical intelligence (2001–2025) and model calibration anchor.

INPE DETER

INPE / IBAMA Enforcement Support
Daily / Weekly Alerts
Primary Role & Methodology Near-real-time deforestation and forest degradation detection system (≥3 ha) designed for tactical field enforcement dispatch (IBAMA/ICMBio) since 2004.
Analytical Nature Rapid reactive detection; identifies canopy loss after clearing activities have commenced, subject to persistent optical cloud cover.
Complementary Relation to This Project DETER flags active clearings; our project operates upstream by predicting multi-feature structural vulnerability *before* tree cover removal begins.

PrevisIA

Imazon / Microsoft / Fundo Vale
Annual Predictive Risk
Primary Role & Methodology AI-based predictive risk model estimating deforestation probability across the Legal Amazon in 25 km² spatial blocks over a 12-month forward horizon.
Analytical Nature Regional risk surface generation published annually to mobilize civil society, public prosecutors, and state environmental secretariats.
Complementary Relation to This Project Closest predictive counterpart; this project complements PrevisIA by evaluating granular spatial pilot density (150,000 cells in Rondônia), explicit SHAP driver attribution (41% road, 23% loss, 21% pop, 15% elevation), interactive 2D/3D visual triage, and client-side policy sensitivity simulation.

MapBiomas Alert

Multi-Institutional NGO Consortium
High-Resolution Validation
Primary Role & Methodology Validates and refines all published deforestation alerts (DETER, SAD, GLAD) using 3-meter PlanetScope daily imagery, cross-referencing rural environmental registries (CAR).
Analytical Nature Post-alert spatial verification reports providing definitive parcel-level audit trails for legal and supply-chain due diligence.
Complementary Relation to This Project Represents a future independent verification partner that could validate whether predicted high-risk frontier cells experienced confirmed clearing.

What Remains to Become an Operational System?

Transparent assessment of the gap between current prototype code and production enterprise deployment.

1. Reproducible Model Package
Current State: Model trained offline; serialized artifacts not bundled in frontend repository.
Required Step: Package Python training code, hyperparameter configs, and ONNX weights into a versioned repo.
2. Live / Scheduled Data Pipelines
Current State: Static precomputed JSON dataset representing the Rondônia pilot grid.
Required Step: Construct automated cloud-native DAGs (e.g., Airflow) to harvest official satellite and road updates.
3. Formal Temporal Validation
Current State: Cross-validated on empirical sample subset; timeline is simulated representation.
Required Step: Multi-year backtesting measuring lead time between high-risk flags and confirmed PRODES clearing.
4. Operational Analyst Workflow
Current State: Executive presentation interface with decision-support walkthroughs.
Required Step: Build authenticated case triage software with task assignment, notes, and verification tracking.
5. Field Verification Feedback Loop
Current State: Clear conceptual boundary; handoff ends at spatial prioritization.
Required Step: Bi-directional sync with mobile field apps to ingest ground inspection results as new training labels.
6. Model Monitoring & Drift Detection
Current State: Static model weights and calibrated global SHAP feature importances.
Required Step: Automated data drift and concept drift telemetry triggering model retraining alerts.
7. Institutional API Integration
Current State: Standalone client-side application with zero live government server integration.
Required Step: Develop standardized OGC-compliant Web Feature Services (WFS) and REST APIs for environmental agency GIS compatibility.
